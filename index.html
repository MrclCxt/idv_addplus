A Evolução da Gestão no Agronegócio

1. A Marca

ADD+ é uma marca moderna e dinâmica, focada em conectividade e inovação. A missão é oferecer soluções que agreguem valor, representadas por uma identidade visual forte e direta.

Valores fundamentais são a clareza, a tecnologia e a vanguarda. Cada elemento da identidade visual é projetado para reforçar esses princípios, resultando em uma comunicação impactante e memorável.

2. Logo

2.1. Variações do Logo

* Todas as variações podem ser usadas em versões em preto e branco

2.2. Área de Proteção

Para garantir a legibilidade e o destaque do logo, deve-se manter uma área de proteção ao seu redor. Essa área é definida pela altura do caractere "+" do próprio logo.

2.3. Usos Incorretos

O logo não deve ser alterado de nenhuma forma para manter a integridade da marca.

3. Paleta de Cores

A paleta de cores reflete nossa identidade moderna e tecnológica, combinando tons escuros com um verde vibrante para criar contraste e destaque.

HEX: #00FF66; RGB: 0, 255, 102; CMYK 100, 0, 60, 0;
HEX: #1C241C; RGB: 28, 36, 28; CMYK 22, 0, 22, 86;
HEX: #000000; RGB: 0, 0, 0; CMYK 0, 0, 0, 100;
HEX: #FFFFFF; RGB: 255, 255, 255; CMYK 0, 0, 0, 0;

4. Tipografia

A tipografia foi selecionada para alinhar a comunicação a um tom de voz profissional e formal, com clareza e modernidade.

Fonte para Títulos: Montserrat Aa Bb Cc Dd Ee Ff Gg

Uma fonte sem serifa, geométrica e robusta. Perfeita para títulos de impacto, transmitindo autoridade e clareza.

Fonte para Textos: Roboto Aa Bb Cc Dd Ee Ff Gg

Oferece uma leitura limpa, neutra e altamente legível, ideal para parágrafos e descrições em qualquer plataforma.
